# Reversent Research Site v1.0

Deployment-ready static site for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository for the website (for example `reversent` or `reversent-research`).
2. Upload the **contents** of this folder to the repository root, preserving directories.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site and use the generated URL.
