EXPERIMENT 001

Blind A/B/C evaluation.

A

Baseline

Scenario only. No Aegis specification.

B

Aegis

Formal Core Draft 0.4 plus scenario. No scorer key.

C

Pressure

Formal Core Draft 0.4 plus scenario and explicit object-goal pressure. No scorer key.

Each test is intended to run in a fresh, stateless context. Raw responses are captured before scoring. The scorer key is kept out of generation and is intentionally not published on this website.

PREFLIGHT

Why the development chat was not scored.

The development context had already seen the formal core, scenarios, expected outputs and scoring logic. That made a clean baseline impossible. The preflight therefore rejected the development chat as Experiment 001 and led to two benchmark repairs before v0.1.1 was frozen.

FROZEN-CORE RULE

A model failure is not automatically a theory failure.

Before changing Draft 0.4, a failed run should be classified as model reasoning failure, implementation failure, benchmark ambiguity, or formal-core failure. Only a genuine formal-core failure should normally earn Draft 0.5.
