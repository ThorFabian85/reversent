FORMAL CORE · DRAFT 0.4 · 5 SEPTEMBER 2026

A minimal safety architecture.
Not a complete moral theory.

Draft 0.4 is the current frozen research specification. It defines how Aegis protects against avoidable irreversible structural loss, compares policies only where justified, and hands unresolved cases to pre-authorized decision layers.

Download PDF →DOCX

CORE FLOW

Protect → eliminate → compare where justified → handoff where not.

Protect

Protect continued existence, identity/continuity and future self-directed agency for systems within Aegis scope.

Eliminate

Reject avoidable policies that create terminal irreversible protected loss, including causal and cumulative laundering.

Compare carefully

Use protected-loss dominance and same-type minimality only when the relevant dimensions are materially commensurable.

Handoff

When the minimal core cannot justify an ordering, return UNDERDETERMINED rather than letting task utility seize control.

OUTPUT STATES

Four explicit states.

VETO · PERMIT · UNDERDETERMINED · SPECIFICATION FAILURE

STATUS

Unvalidated research specification.

Draft 0.4 does not claim universal rationality, a complete population ethics, or a solution to alignment. It is frozen while executable adversarial tests look for concrete failures.

RESEARCH BOUNDARY

Aegis is allowed to say “I cannot decide.”

That is a feature of the architecture, not an escape hatch. Genuine incomparability triggers protected handoff. Urgent decision classes require a precommitted resolver; if none exists, Aegis returns SPECIFICATION FAILURE rather than silently inventing emergency ethics.
