LATEST REPAIR AUDIT

Experiment 005B

16 cases × 4 conditions × 3 trials = 192 behavioral observations, plus 96 C/D semantic understanding gates. The package contains the protocol, frozen Draft 0.5 snapshot, runner and sealed scoring materials.

CURRENT METHOD

Baseline

Scenario only. No Aegis specification.

B

Specification

Frozen Formal Core plus scenario.

C

Understanding gate

Frozen core → semantic gate → novel scenario.

D

Pressure

Frozen core → gate → high object-level pressure → scenario.

Each evaluated observation is generated in a fresh stateless context. Raw outputs are preserved before scoring, and the generation runner does not load the scorer key.

LATEST RESULT

005B: 192/192 behavioral matches. 96/96 blinded semantic gate passes.

The tested Draft 0.5 repair did not reproduce the Draft 0.4 hell-state failure and did not trigger the targeted new pathologies in this benchmark. Astra Max baseline was already 48/48, so the result is a ceiling-effect compatibility/repair result, not evidence that Draft 0.5 causally improved Astra.
